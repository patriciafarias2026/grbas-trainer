# GRBAS Trainer

Herramienta educativa de entrenamiento audioperceptual de la calidad vocal (GRBAS) basada en la
Perceptual Voice Qualities Database (PVQD, Walden 2020). / Educational auditory-perceptual training tool (GRBAS) based on the PVQD.

- Abrir `index.html` (ES/EN). Todo corre en el navegador; no se envían datos.
- Los audios **no** están incluidos: descargarlos de https://data.mendeley.com/datasets/9dz247gnyb/3 (CC BY 4.0).
- Alcance: uso educativo; no es un instrumento de diagnóstico clínico.
